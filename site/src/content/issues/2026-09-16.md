  summary: "A formal model of decomposition asks how much of what leaf agents discover reaches the root. Model each agent as keeping any handed item with probability r(b); if r(b)=1/b every tree delivers exactly one finding, verified to 1e-15 on 20,000 random trees. Under r(b)=Cb^(-δ), a depth-k tree yields C^k·N^(1-δ): task size and architecture separate, architecture contributes only C≤1 per level, so flat is optimal for yield.
