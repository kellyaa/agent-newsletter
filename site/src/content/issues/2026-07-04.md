  summary: "Multi-Head Recurrent Memory diagnoses why recurrent memory agents degrade with context length: decomposing performance into capture and retention shows retention is the bottleneck, collapsing because a monolithic text-block memory risks overwriting itself on every update. MHM partitions memory into independent heads with stage-wise select-then-update, so only one head writes per step while others are structurally shielded. The training-free MHM-LRU variant adds zero token overhead and lifts RULER-HQA retention at 896K tokens from under 30% to 73.96%. Shifting retention from model behavior to architecture is a clean, well-motivated move."
  takeaway: "Long-context memory failures are mostly overwrite-driven retention loss, not capture loss—partitioning memory into shielded heads fixes it without retraining or extra tokens."
