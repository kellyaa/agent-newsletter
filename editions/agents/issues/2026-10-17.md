  summary: "A sharp diagnosis of context compaction failure: because compaction prompts ask summarizers for decisions and next steps, each summary blends environment facts with the compressor's own reasoning, and the agent can't tell them apart later. In one widely used compressor, 83% of failed runs trace to an action executing an unsupported summary entry. The fix, Source-Judged Compaction, scores each entry for whether an environment output or prior summary supports it and drops the rest — training-free, one judge call per compaction, 2.1–8.9% reliability gains on AppWorld and OfficeBench with no extra agent tokens."
