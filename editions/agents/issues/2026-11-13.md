  summary: "This paper tests whether small language models can write the security artifacts that enforcement defenses like CaMeL, Progent, IPIGuard, and DRIFT rely on — and across 15 open-weight models (13 between 1.7B and 12B), they can't: the model-written policies and graphs admit attacks on most models, and CaMeL's programs fail to run in up to 68% of episodes.   author: "Yubo Ruan, Tao Peng, Jiao Zhang, Chuanguo Ma, Lei Xu, Han Zhou, Wenwu Wang, Xiafei Lv, Xingjie Zhou, Guiju Fan, Hao Wang, Fenghui Zhang, Mao Miao, Shuo Li"

  summary: "Folio manages long-horizon context by recording three linked levels as the agent runs — a short turn note the model writes, an event manifest the runtime logs, and captured source records — then folds older turns to coarser views programmatically, printing handles so recovery tools can page back to evidence when needed. Because the views already exist, no model summarization pass is required.
