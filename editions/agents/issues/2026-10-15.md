  score: 8

  summary: "CTXGAP measures what coding agents omit from their user-facing reports. Across 37 tasks and 4,799 probes, agents answer 93.6% of task-state questions when asked, and full-context readers recover 92.7% — but report-only readers recover just 52.0%, a 40.7-point gap that holds at 34.8 points even at verified-fix checkpoints.   summary: "P2Patch targets a real weakness in agentic program repair: patches validated against the same evidence used to build them can block one exploit while staying vulnerable to a variant. It runs an adversarial loop — an exploitation agent builds a reproducing PoV, a patching agent repairs, then the exploiter attacks the patched program for a distinct same-vuln exploit, with construction-time PoVs kept separate from held-out oracles.   takeaway: "Validating a vulnerability patch against the same trace that motivated it overstates safety; adversarial re-exploitation is a measurably stronger acceptance test."
