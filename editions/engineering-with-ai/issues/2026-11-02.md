  summary: "Import errors are a top failure cause in LLM test generation, and naive grammar-constrained decoding fixes them but causes degenerate 'import streaks' that burn the token budget before a test appears. CBDL constrains decoding with lookup to guarantee valid imports without the repetition. On Python and Java it hits 100% valid imports versus 45%, 10%, and 43% unresolved for RAG, LIBRO, and agentic repair, converting 14% of import errors into correct tests and lifting correctness 1-4 points, plus 2-7 more when freeing repair budget."
