  summary: "Foresight-SWE asks whether coding agents anticipate problems their own changes introduce. Each of its 212 samples across 4 languages and 35 repos pairs a PR with a later PR that fixes the defect the first one caused. The metric rewards an agent only when it resolves the original task and avoids that downstream defect. Across eleven models, the foresight resolve rate ran from 6.13% to 24.53%. Agents close the ticket in front of them and rarely see the bug they are planting."
